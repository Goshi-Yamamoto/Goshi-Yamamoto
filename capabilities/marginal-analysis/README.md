# Marginal Analysis

## Purpose
This Excel model helps find the best combination of tomatoes, carrots, and mesclun to maximize the farm's seasonal profit.

## What It Does
The model calculates labor hours, revenue, fertilizer costs, labor costs, and seasonal profit. It also compares marginal costs for each crop and uses Excel Solver to find the best number of beds.

## How to Use
Open `model.xlsx` in Microsoft Excel. Check the input values and change the number of beds if needed. Use Excel Solver to maximize seasonal profit while following the land and labor limits. Check the results in the `Checks & Audit` sheet.
